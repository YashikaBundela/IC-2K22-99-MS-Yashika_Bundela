# Lab 04 - Image Enhancement

## Objective

The objective of this lab is to improve the visual quality of digital images using different image enhancement techniques.

## Features

The program performs the following operations:

1. Contrast Enhancement
2. Brightness Correction
3. Noise Reduction
4. Image Sharpening
5. Image Upscaling
6. Combined Image Enhancement

## Technologies Used

- Python
- OpenCV
- NumPy

## Supported Image Formats

- JPG
- JPEG
- PNG
- BMP
- WEBP
- TIFF
